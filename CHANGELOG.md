# Changelog

## 0.1.0

Initial source release.

- Native macOS screen history with ScreenCaptureKit and Vision OCR.
- Capture support for connected displays and available windows across desktops.
- Global quick search with Shift-Command-Space.
- Automatic Jev search with user-supplied TypeSafe or Vercel AI Gateway keys.
- Local search when no key exists or the provider request fails.
- Keychain credential storage and explicit upload disclosure.
- Image zoom, recognized-text previews, app filters, and date filters.
- Automatic recording with seven-day and 5,000-capture retention limits.
- Command-Q keeps recording and quick search active in the menu bar.
- Synthetic demo content and automated macOS build checks.

This source release has no notarized installer. Live responses from both Jev providers require separate validation with account keys.
