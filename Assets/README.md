# Seen app icon

The built-in image-generation tool created `AppIcon.png`. The build script converts it into the macOS icon sizes.
The image was generated before the app name changed to Seen. It contains no text.

## Generation prompt

Use case: logo-brand
Asset type: production macOS application icon for a local screen-history search app named Rewind But Fast.
Primary request: Create one exceptionally refined app icon. A single sculpted rewind mark, two left-pointing rounded chevrons joined as a continuous folded ribbon, centered on a pearl-white rounded square tile. The ribbon is satin violet with gentle periwinkle highlights and rich indigo inner folds. Suggest returning to a remembered moment.
Composition: square 1024 x 1024 canvas; the macOS squircle tile occupies 88 percent of the canvas, centered with generous transparent margins. Strong readable silhouette at 32 pixels. Straight-on view, no perspective tilt.
Style: meticulous macOS icon craft, understated three-dimensional depth, smooth rounded edges, soft ambient shadow, subtle material shading. Warm pearl tile, one violet ribbon symbol.
Constraints: genuine transparent background outside the tile. No letters, no words, no extra symbols, no magnifying glass, no mockup, no surrounding scene, no watermark. Deliver a single finished icon, not a contact sheet.
